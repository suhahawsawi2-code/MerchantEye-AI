# محرك التحليل — عين التاجر AI

هذا المجلد هو خوارزمية الرؤية الحاسوبية الفعلية للمشروع. يحلّل فيديو طابور بـ **YOLOv8** لاكتشاف الأشخاص و**ByteTrack** لتتبّعهم، ثم يحسب:

- عدد العملاء في الصورة
- عدد المنتظرين داخل **منطقة الطابور** (ROI)
- وقت انتظار كل شخص = المدة التي يبقاها داخل منطقة الطابور
- استبعاد الموظفين: من يقف معظم الوقت في **منطقة الموظفين** (خلف الكاونتر) يُحسب موظفاً، لا عميلاً
- تنبيه وتوصية تلقائية عند تجاوز حد الانتظار أو طول الطابور

## ١. التثبيت (مرة واحدة)

يحتاج Python 3.9 أو أحدث.

```bash
cd analysis
pip install -r requirements.txt
```

نموذج `yolov8n.pt` يُحمَّل تلقائياً أول مرة.

## ٢. ضبط المنطقتين على الفيديو

الإحداثيات نسبية من 0 إلى 1، حيث (0,0) أعلى يسار الصورة و(1,1) أسفل يمينها.

```bash
python analyze.py --video queue.mp4 --preview-zones \
  --queue-zone "0.30,0.40 0.75,0.40 0.75,0.95 0.30,0.95" \
  --staff-zone "0.78,0.30 1.0,0.30 1.0,0.90 0.78,0.90"
```

افتحي `output/zones_preview.jpg`، وعدّلي الأرقام حتى يغطي المربع الأزرق مكان وقوف الطابور، والرمادي مكان الكاشير.

## ٣. التحليل

```bash
python analyze.py --video queue.mp4 \
  --queue-zone "..." --staff-zone "..." \
  --wait-threshold 180 --queue-limit 4
```

| الخيار | المعنى |
|---|---|
| `--wait-threshold` | أقصى انتظار مقبول بالثواني، يظهر تنبيه عند تجاوزه |
| `--queue-limit` | طول الطابور الذي يُطلق التنبيه |
| `--model yolov8s.pt` | نموذج أدق لكنه أبطأ |
| `--stride 2` | تحليل كل إطار ثانٍ لتسريع المعالجة |

**المخرجات في مجلد `output/`:**
- `queue_annotated.mp4`: الفيديو وعليه مربعات حقيقية، ورقم كل شخص، ووقت انتظاره، ونسبة الثقة
- `queue_analysis.json`: النتائج ثانية بثانية مع ملخص كامل

## ٤. عرض النتائج في الموقع

**الطريقة الأولى:** من لوحة التحكم، زر **«رفع نتيجة تحليل»**، واختاري الملفين معاً (`_annotated.mp4` و`_analysis.json`).

**الطريقة الثانية (للعرض الدائم):** انسخي الملفين إلى `public/demo/` بالاسمين `annotated.mp4` و`analysis.json`، ثم ارفعي التعديل على GitHub. سيعرضهما الموقع تلقائياً.

## ٥. قياس الدقة (لأرقام الملصق)

1. أوقفي الفيديو كل 5 ثوانٍ، وعدّي المنتظرين يدوياً، وسجّلي ذلك في `counts.csv`:
   ```
   time_sec,true_count
   0,2
   5,3
   ```
2. احسبي بالساعة وقت انتظار نحو 10 أشخاص، وقارنيه بالرقم الظاهر على الفيديو، وسجّلي ذلك في `waits.csv`:
   ```
   person,true_wait_sec,system_wait_sec
   1,95,88
   ```
3. شغّلي:
   ```bash
   python evaluate.py --analysis output/queue_analysis.json --counts counts.csv --waits waits.csv
   ```

يطبع السكربت خطأ العدّ (MAE)، وخطأ وقت الانتظار، وسرعة المعالجة (FPS). هذه هي الأرقام التي توضع في جدول Key Results في الملصق.

## ملاحظات صادقة للعرض أمام الحكام

- **مؤشر تجربة العملاء:** معادلة بسيطة ومعلنة. يبدأ من 100، ويخصم حتى 50 نقطة حسب قرب متوسط الانتظار من الحد، وحتى 30 نقطة إذا زاد الطابور على شخصين.
- **تمييز الموظفين:** يعتمد على المكان (منطقة الموظفين)، لا على الزي.
- **الخصوصية:** النظام لا يستخدم التعرف على الوجوه. يخزّن أرقاماً مجهولة (ID ومواقع) فقط.
- **الحدود:** الزحام الشديد والتداخل قد يسبّبان أخطاء في العدّ أو تبديلاً في الأرقام، والكاميرا من الأعلى تعطي أفضل نتيجة.
